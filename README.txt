MUHAMMAD ANAS — DYNAMIC ARTIST PORTFOLIO
========================================

WHAT'S NEW
- Purple / neon visual theme, while keeping the original portfolio sections and layout.
- 5 gallery panels: Digital Art, Graphic Design, Streamer Assets, Branding, 3D & Motion.
- Each panel supports up to 15 images (75 total).
- Click "Manage Gallery" to upload multiple JPG, PNG, WEBP or GIF files.
- Edit artwork title/description or remove an image from the manager.
- Uploaded images are saved in IndexedDB in the browser and remain after refresh.

HOW TO USE
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Click "Manage Gallery".
4. Choose a panel, select images, and click "Upload selected".
5. Click Edit or Remove on any uploaded image to manage it.
6. Edit your name, email and social links in config.js if needed.

IMPORTANT ABOUT DYNAMIC UPLOADS
This version is a static website with browser-local storage. Uploads are saved only
in the browser/device where they were added. They do not automatically appear for
other visitors or on another device. To make uploads public and sync them across
devices, connect a backend such as Supabase or Firebase and deploy the website
over HTTPS. GitHub Pages alone cannot store uploaded files on its server.

PUBLISH
Upload index.html, config.js, script.js, style.css and the artworks folder to
GitHub Pages or Netlify. Keep all files in the same structure.


BASIC ARTWORK PROTECTION
- Public gallery artwork previews display a visible MUHAMMAD ANAS watermark.
- Right-click on gallery/lightbox artwork and image dragging are disabled as casual deterrents.
- This cannot prevent screenshots, screen recording, browser developer tools, or determined copying.
- For stronger protection, publish only resized/watermarked previews and keep original files private.
